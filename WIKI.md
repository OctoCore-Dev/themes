# 🎨 Полная Вики по созданию тем оформления для OctoCore / obxodka

Добро пожаловать в официальное руководство по созданию пользовательских и живых тем для **OctoCore / obxodka**!

В этом руководстве детально разобран **каждый параметр** спецификации манифеста (`theme.json`), объясняется работа адаптивных рамок экрана **9-Slice (Nine-Patch)** для ПК и смартфонов, настройка 4-фазных анимированных кнопок VPN, видео-фонов, VFX-частиц и звуковых эффектов.

---

## 📁 1. Архитектура и структура папки темы

Каждая тема представляет собой отдельную папку (или `.zip` архив). В официальном репозитории [OctoCore-Dev/themes](https://github.com/OctoCore-Dev/themes) тема размещается в каталоге `themes/<theme-id>/`:

```text
themes/my-awesome-theme/
├── theme.json               # Главный конфигурационный манифест темы (обязателен)
├── preview.png              # Превью темы для магазина 600x400 (PNG/JPG, обязателен)
├── icon.png                 # Иконка темы 128x128 или 256x256 (PNG/JPG, опционально)
└── assets/                  # Каталог графических и медиа-ресурсов
    ├── bg.mp4 / bg.jpg      # Фоновое видео или изображение
    ├── frames/              # Рамки окна (desktop / mobile / 9-slice)
    │   ├── frame_desktop.png
    │   └── frame_mobile.png
    ├── buttons/             # Кнопка подключения (PNG или Animated WebP с прозрачностью)
    │   ├── button_idle.webp
    │   ├── button_connecting.webp
    │   ├── button_active.webp
    │   └── button_error.webp
    ├── stickers/            # Угловые декорации (верх-лево, верх-право и т.д.)
    ├── particles/           # Кастомные спрайты для эффектов частиц
    └── sounds/              # Звуковые дорожки (.wav / .mp3)
        ├── click.wav
        ├── connect.wav
        └── disconnect.wav
```

## 📑 2. Полный справочник всех параметров `theme.json`

Ниже приведен детальный разбор всех секций и параметров манифеста темы.

### 2.1. Метаданные темы (Корневой уровень)

| Параметр | Тип | Обязательный? | Описание | Пример |
| :--- | :--- | :---: | :--- | :--- |
| `$schema` | `string` | Нет | Ссылка на JSON-схему для автокомплита в редакторе (VS Code / Rider). | `"../../schemas/theme.v4.json"` |
| `id` | `string` | **Да** | Уникальный идентификатор темы в `kebab-case`. Допустимы только строчные латинские буквы `a-z`, цифры `0-9` и дефисы `-`. Должен совпадать с именем папки темы! | `"cyber-neon"` |
| `name` | `string` | **Да** | Отображаемое название темы в витрине и настройках. | `"Cyber Neon 2077"` |
| `author` | `string` | **Да** | Имя или никнейм автора/студии. Если указано `"OctoCore"`, в магазине отображается бейдж **`[✓ Официальная]`**. | `"Alex Dev"` |
| `version` | `string` | **Да** | Версия темы по стандарту SemVer (`X.Y.Z`). | `"1.0.0"` |
| `description` | `string` | Нет | Описание темы, её стиля и атмосферы (до 250 символов). | `"Неоновая живая тема с видео-фоном ночного города"` |
| `tags` | `array<string>` | Нет | Список тегов для поиска и фильтрации: `dark`, `light`, `anime`, `neon`, `live`, `video`, `minimal`, `nature`, `cyberpunk`. | `["neon", "dark", "live"]` |
| `supportedApps`| `array<string>` | Нет | Список совместимых приложений (по умолчанию `["*"]`). | `["*"]` или `["obxodka"]` |

### 2.2. Цветовая палитра (`core.colors`)

Все цвета указываются в формате HEX: `#RRGGBB` или `#AARRGGBB` (с альфа-каналом прозрачности).

```json
"core": {
  "colors": {
    "BgBase": "#0E0E14",
    "BgSurface": "#181824",
    "BgElevated": "#222234",
    "BgInput": "#14141E",
    "Primary": "#0078D4",
    "PrimaryBright": "#2B88D8",
    "PrimaryDim": "#005A9E",
    "Accent": "#00E5FF",
    "TextPrimary": "#FFFFFF",
    "TextSecondary": "#A0A0B2",
    "TextMuted": "#606075",
    "SolidBorderDark": "#2E2E42",
    "BorderSubtle": "#252538",
    "BorderMedium": "#383852",
    "Success": "#10B981",
    "Warning": "#F59E0B",
    "Error": "#EF4444"
  }
}
```

#### Назначение каждого цветового токена:
1. **`BgBase`** *(Обязательный)*: Фундаментальный цвет заднего плана окна/экрана приложения. По нему движок автоматически определяет яркость темы и контраст системных кнопок заголовка окна Windows и статус-бара Android.
2. **`BgSurface`** *(Обязательный)*: Цвет карточек, контейнеров списков и основного контента.
3. **`BgElevated`**: Цвет приподнятых плашек (всплывающие модальные окна, выпадающие списки, контекстные меню).
4. **`BgInput`**: Цвет подложки полей ввода текста, слайдеров и переключателей.
5. **`Primary`** *(Обязательный)*: Главный акцентный цвет темы (активные кнопки, радиокнопки, акцентные бейджи, ползунки).
6. **`PrimaryBright`**: Осветленный/яркий акцент для состояний ховера (наведение мыши) и внешнего неонового свечения (Glow).
7. **`PrimaryDim`**: Затемненный акцент для рамок кнопок и неактивных индикаторов.
8. **`Accent`**: Дополнительный акцентный цвет (подсветка второстепенных действий, искры VFX, пинг серверов).
9. **`TextPrimary`** *(Обязательный)*: Основной текст заголовков, имен серверов и кнопок (должен быть максимально контрастным к `BgBase` и `BgSurface`).
10. **`TextSecondary`**: Второстепенный текст (подписи, статусы, второстепенная статистика).
11. **`TextMuted`**: Приглушенный текст (плейсхолдеры в полях ввода, подсказки, неактивные табы).
12. **`SolidBorderDark`**: Цвет разделительных линий между блоками интерфейса.
13. **`BorderSubtle`**: Тонкий, едва заметный контур вокруг карточек серверов.
14. **`BorderMedium`**: Контур активных или выделенных элементов.
15. **`Success`**: Цвет успешных событий (зеленый): индикатор активного защищенного соединения, статус «Подключено», отличный пинг.
16. **`Warning`**: Цвет предупреждений (желтый/оранжевый): низкий остаток тарифа, нестабильное соединение, повторное подключение.
17. **`Error`**: Цвет критических ситуаций (красный): ошибка авторизации, сбой соединения, сервер недоступен.

### 2.3. Градиенты (`core.gradients`)

Позволяют задать плавные цветовые переходы для главного фона и акцентных плашек:

```json
"gradients": {
  "PrimaryGradient": {
    "angle": 45,
    "stops": ["#0078D4", "#00E5FF"]
  },
  "SurfaceGradient": {
    "angle": 135,
    "stops": ["#1E1220", "#0D0912"]
  }
}
```
- `angle`: угол наклона градиента в градусах (0° — снизу вверх, 90° — слева направо, 45° — по диагонали).
- `stops`: массив цветов перехода (минимум 2 цвета).

### 2.4. Параметры интерфейса и шрифты (`core.ui`)

```json
"ui": {
  "CornerRadius": 16,
  "BlurIntensity": 20,
  "BorderThickness": 1.0,
  "CardOpacity": 0.85,
  "FontFile": "assets/fonts/CustomFont.ttf"
}
```
- **`CornerRadius`**: Радиус скругления углов карточек и кнопок (в пикселях, по умолчанию `16`).
- **`BlurIntensity`**: Сила эффекта матового стекла (Glassmorphism) под карточками при включенном видео/фото-фоне (по умолчанию `20`).
- **`BorderThickness`**: Толщина внешних рамок карточек и полей (по умолчанию `1.0`).
- **`CardOpacity`**: Прозрачность карточек интерфейса поверх живого фона (от `0.20` до `1.00`, по умолчанию `0.85`). Пользователь может регулировать её в приложении отдельным ползунком.
- **`FontFile`**: Относительный путь к файлу кастомного шрифта (`.ttf` / `.otf`).

### 2.5. Звуковое сопровождение (`core.sounds`)

```json
"sounds": {
  "click": "assets/sounds/click.wav",
  "notification": "assets/sounds/notify.wav",
  "connect": "assets/sounds/vpn_connected.wav",
  "disconnect": "assets/sounds/vpn_disconnected.wav"
}
```
- **`click`**: Звук нажатия на элементы управления и вкладки.
- **`notification`**: Звук поступления уведомлений или сообщений.
- **`connect`**: Звук при успешном установлении VPN-соединения (кинематографичный аккорд / чип / сигнал).
- **`disconnect`**: Звук при остановке защиты VPN.

> ℹ️ Рекомендуемый формат: несжатый `.wav` (PCM 16-bit 44.1kHz Stereo) или легковесный `.mp3`. Размер каждого файла звука не должен превышать 1–2 МБ.

### 2.6. Задний фон (`background`)

Тема может иметь статичный постер, бесшовный видео-луп или градиентный фон:

```json
"background": {
  "type": "video",
  "videoSource": "assets/bg_loop.mp4",
  "imageSource": "assets/bg_poster.jpg",
  "fallbackImage": "assets/bg_poster.jpg",
  "loop": true,
  "muted": true,
  "opacity": 0.45
}
```
- **`type`**: Тип фона: `"image"`, `"video"`, или `"gradient"`.
- **`videoSource`**: Путь к MP4/WebM файлу видео.
- **`imageSource`**: Путь к статическому изображению (`.jpg`, `.png`, `.webp`).
- **`fallbackImage`**: Резервное статическое изображение. Отображается, если пользователь выключил видео-фон в настройках («Энергосбережение») или на слабых устройствах.
- **`loop`**: Зацикливать видео (`true` / `false`).
- **`muted`**: Заглушать ли звук в видео (`true`).
- **`opacity`**: Непрозрачность подложки (от `0.0` до `1.0`). Рекомендуется `0.35`–`0.55`, чтобы интерфейс приложения оставался легко читаемым.

## 🖼️ 3. Адаптивные рамки экрана: Технология 9-Slice (Nine-Patch)

### 3.1. В чем проблема обычной рамки на смартфонах?
- На ПК экраны альбомные (16:9, 16:10, разрешением 1920x1080 или шире).
- На смартфонах экраны портретные (9:19.5, 9:20, например 1080x2400).
- Если обычную горизонтальную картинку рамки растянуть на телефон, её углы сплющатся в овал, а вертикальные линии деформируются. Если применить `AspectFill` — боковые границы рамки просто срежутся за экраном.

### 3.2. Как работает 9-Slice
Картинка рамки логически делится четырьмя линиями срезов (`top`, `right`, `bottom`, `left`) на **9 независимых зон**:

```text
       left                                  right
         |                                     |
   +-----+-------------------------------------+-----+
   | (1) |                 (2)                 | (3) |
   | Top |              Top Edge               | Top | --- top
   | Left|          (тянется по ширине)        |Right|
   +-----+-------------------------------------+-----+
   |     |                                     |     |
   | (4) |                 (5)                 | (6) |
   |Left |            Центральная              |Right|
   |Edge |               область               |Edge |
   |(тян)|             (прозрачно)             |(тян)|
   +-----+-------------------------------------+-----+
   | (7) |                 (8)                 | (9) |
   | Bot |             Bottom Edge             | Bot | --- bottom
   | Left|          (тянется по ширине)        |Right|
   +-----+-------------------------------------+-----+
```

- **4 угла (1, 3, 7, 9)**: Рисуются в пропорциях **1:1 без искажений** в любых разрешениях! Узорные виньетки, закругления, драконы или кристаллы в углах остаются идеально четкими.
- **4 грани (2, 4, 6, 8)**: Планки рамки аккуратно растягиваются вдоль краев экрана.
- **Центр (5)**: Полностью прозрачный, внутри него отображается контент приложения.

### 3.3. Как рассчитать параметры `frameSlice`:
1. Откройте изображение рамки в любом графическом редакторе (Photoshop, Figma, GIMP).
2. Замерьте в пикселях ширину и высоту декоративного угла (например, декоративный узор занимает 70 пикселей сверху и по 70 пикселей по бокам).
3. Пропишите эти значения в `theme.json`:
   ```json
   "frameSlice": {
     "top": 70,
     "right": 70,
     "bottom": 70,
     "left": 70
   }
   ```
4. Если вы также предоставляете отдельную вертикальную рамку для смартфонов (`screenFrameMobile`), укажите для нее свои срезы в `frameSliceMobile`.

## 🔘 4. Анимированные и статичные кнопки VPN (4 состояния)

Кнопка переключения VPN поддерживает полный цикл жизни соединения.

### 4 состояния кнопки:
1. **`Idle`** (`buttonImageIdle` / `buttonVideoIdle`): Режим ожидания. VPN отключен.
2. **`Connecting`** (`buttonImageConnecting` / `buttonVideoConnecting`): Процесс рукопожатия, шифрование ключей, запуск туннеля (анимация вращения, зарядки энергии или пульсации).
3. **`Active`** (`buttonImageActive` / `buttonVideoActive`): Защита активна. Туннель подключен (сияние, открытая форма, неоновое свечение).
4. **`Error`** (`buttonImageError` / `buttonVideoError`): Ошибка связи или сбой соединения (тревожный сигнал, предупреждающая анимация).

### Важные правила для графики кнопки:
- **Обязателен прозрачный альфа-канал!** Кнопка не должна иметь черный или белый прямоугольный фон, иначе нарушится форма.
- **Формат живых анимаций**: Рекомендуется **Animated WebP** (`.webp`) с альфа-каналом. Он работает на 60 FPS прямо через SkiaSharp GPU-пайплайн с минимальным потреблением ОЗУ.
- Движок автоматически переключается между анимациями с кинематографичным пружинящим **Cross-Fade** переходом.

## ✨ 5. Система частиц VFX (`vfx`)

Движок визуальных эффектов работает на базе SkiaSharp и рисует анимированные частицы поверх или позади контента.

```json
"vfx": {
  "particles": "sakura_petals",
  "particleSprite": "assets/particles/petal.png",
  "intensity": 0.6,
  "speed": 1.0,
  "size": 1.0,
  "color": "#FFB8D0"
}
```

### Встроенные типы частиц (`particles`):
- `"sakura_petals"`: Падающие лепестки сакуры с покачиванием по синусоиде и вращением.
- `"crows_feathers"`: Падающие черные перья воронов.
- `"neon_sparks"`: Искры неоновой энергии, поднимающиеся снизу вверх с эффектом мерцания.
- `"snow"`: Реалистичный падающий снег.
- `"fireflies"`: Плавно парящие светлячки с мерцанием яркости.
- `"bubbles"`: Поднимающиеся полупрозрачные пузыри.
- `"rain"`: Вертикальные капли дождя.
- `"none"`: Отключение частиц.
- `"custom"`: Использование собственного спрайта из `particleSprite`.

## 🚀 6. Пошаговый гайд: Создание и публикация темы в GitHub

### Шаг 1: Форк репозитория
Форкните официальный репозиторий тем:
```bash
gh repo fork OctoCore-Dev/themes --clone
cd themes
```

### Шаг 2: Создайте каталог для вашей темы
Создайте папку в `themes/<ваше-название-темы>/`:
```bash
mkdir -p themes/my-theme/assets/{frames,buttons,sounds,particles}
```

### Шаг 3: Подготовьте ассеты
1. `preview.png` — обложка темы размером 600x400 (PNG или JPG).
2. `icon.png` — квадратная иконка 128x128.
3. Сохраните фон, рамки, звуки и кнопки в папку `assets/`.

### Шаг 4: Напишите `theme.json`
Создайте `theme.json` и заполните все параметры по спецификации выше.

### Шаг 5: Локальная валидация каталога
В корне репозитория запустите скрипт валидации:
```bash
node scripts/build-catalog.js
```
Скрипт автоматически проверит:
- Корректность JSON-манифеста и обязательных полей.
- Отсутствие опасных путей и выходов за каталог (Path Traversal / Zip Slip).
- Существование всех указанных картинок, рамок и звуков.
- Лимиты по весу файлов.

### Шаг 6: Отправьте Pull Request
```bash
git checkout -b feature/new-theme-my-theme
git add .
git commit -m "feat(themes): add my-theme"
git push origin feature/new-theme-my-theme
gh pr create --title "Добавлена тема My Theme" --body "Описание темы..."
```
После одобрения модераторами тема появится в витрине приложения у всех пользователей!
