# 🚀 Пошаговое руководство: создание и публикация темы

Как добавить свою тему в официальный каталог [OctoCore-Dev/themes](https://github.com/OctoCore-Dev/themes), чтобы она стала доступна всем пользователям приложения.

---

## Шаг 1: Форкните репозиторий тем
Сделайте форк репозитория и клонируйте его:
```bash
gh repo fork OctoCore-Dev/themes --clone
cd themes
```

---

## Шаг 2: Создайте папку вашей темы
Имя папки должно быть в `kebab-case` и строго совпадать с полем `"id"` в манифесте:
```bash
mkdir -p themes/my-theme/assets/{frames,buttons,sounds,particles}
```

---

## Шаг 3: Подготовьте обязательные файлы
1. **`preview.png`**: Обложка темы для витрины магазина (рекомендуется **600×400**).
2. **`icon.png`**: Иконка темы (квадратная, **128×128** или **256×256**).
3. **`theme.json`**: Манифест со свойствами и ссылками на ассеты (см. [[Справочник theme.json|Theme-Parameters]]).

---

## Шаг 4: Проверьте тему локальным скриптом
В корне репозитория запустите скрипт валидации:
```bash
node scripts/build-catalog.js
```
Скрипт автоматически проверит:
- ✅ Корректность синтаксиса JSON и схемы.
- ✅ Наличие всех обязательных полей (`id`, `name`, `author`, `version`, `colors.Primary`, `colors.BgBase`).
- ✅ Безопасность путей (защита от Path Traversal и запрещенных расширений).
- ✅ Существование всех указанных картинок, рамок, звуков и шрифтов.
- ✅ Соблюдение лимитов размера темы (не более 35 МБ суммарно).

---

## Шаг 5: Отправьте Pull Request
```bash
git checkout -b feature/theme-my-theme
git add .
git commit -m "feat(themes): add my-theme"
git push origin feature/theme-my-theme
gh pr create --title "Добавлена тема My Theme" --body "Описание темы..."
```
После проверки автоматическим GitHub Actions CI и одобрения модератором ваша тема появится в приложении у всех пользователей!
