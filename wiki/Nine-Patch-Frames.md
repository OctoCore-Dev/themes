# 🖼️ Руководство по адаптивным рамкам 9-Slice (Nine-Patch)

В экосистеме OctoCore / obxodka рамки экрана поддерживают современную технологию **9-Slice (Nine-Patch)** на базе графического движка **SkiaSharp**. Это позволяет одной рамке идеально масштабироваться под экраны с любыми соотношениями сторон: от ультрашироких ПК мониторов (21:9) до узких смартфонов (9:20).

---

## 1. В чем проблема обычной рамки на смартфонах?
- На ПК мониторы горизонтальные (16:9, например 1920×1080).
- На смартфонах экраны вертикальные (9:19.5, например 1080×2400).
- При обычном растягивании (`Aspect="Fill"`) рамка десктопа превращается на телефоне в сплющенное месиво: круглые узоры становятся овалами, боковые грани истончаются в нитку, а верх и низ утолщаются.
- При `Aspect="AspectFill"` срезается более 60% ширины рамки, из-за чего боковые рамки вообще исчезают за экраном.

---

## 2. Как работает 9-Slice
Картинка рамки делится четырьмя линиями срезов (`top`, `right`, `bottom`, `left`) на **9 независимых областей**:

```text
       left                                  right
         |                                     |
   +-----+-------------------------------------+-----+
   | (1) |                 (2)                 | (3) |
   | Top |              Top Edge               | Top | --- top
   | Left|          (тянется по ширине)        |Right|
   +-----+-------------------------------------+-----+
   |     |                                     |     |
   | (4) |                 (5)                 | (6) |
   |Left |            Центральная              |Right|
   |Edge |               область               |Edge |
   |(тян)|             (прозрачно)             |(тян)|
   +-----+-------------------------------------+-----+
   | (7) |                 (8)                 | (9) |
   | Bot |             Bottom Edge             | Bot | --- bottom
   | Left|          (тянется по ширине)        |Right|
   +-----+-------------------------------------+-----+
```

- **4 фиксированных угла (1, 3, 7, 9)**: Отрисовываются видеокартой в пропорциях **1:1 без малейших искажений**! Узоры, ветви сакуры, орнаменты и персонажи в углах остаются безупречно четкими.
- **4 масштабируемые грани (2, 4, 6, 8)**: Верх и низ аккуратно растягиваются по горизонтали, а левая и правая грани — по вертикали.
- **Центральная зона (5)**: Остается полностью прозрачной, позволяя взаимодействовать с интерфейсом приложения.

---

## 3. Конфигурация в `theme.json`

В манифесте темы параметры срезов указываются в секции `decorations`:

```json
"decorations": {
  "screenFrame": "assets/frames/frame_desktop.png",
  "screenFrameMobile": "assets/frames/frame_mobile.png",
  "frameSlice": {
    "top": 70,
    "right": 70,
    "bottom": 70,
    "left": 70
  },
  "frameSliceMobile": {
    "top": 40,
    "right": 40,
    "bottom": 40,
    "left": 40
  }
}
```

- **`screenFrame`**: Путь к десктопной рамке.
- **`screenFrameMobile`**: Опциональный отдельный вертикальный файл рамки для смартфонов.
- **`frameSlice`**: Срезы в пикселях для десктопной или универсальной рамки.
- **`frameSliceMobile`**: Опциональные срезы для мобильной рамки.

---

## 4. Как замерить срезы для своего изображения:
1. Откройте PNG файл вашей рамки в Figma, Photoshop или GIMP.
2. Посмотрите на размер декоративного элемента в верхнем левом углу. Например, орнамент занимает 65 пикселей сверху и 65 пикселей слева.
3. Проверьте правый и нижний углы.
4. Пропишите эти числа в объект `frameSlice`:
   ```json
   "frameSlice": {
     "top": 65,
     "right": 65,
     "bottom": 65,
     "left": 65
   }
   ```
5. Если автор не указал `frameSlice`, движок приложения автоматически применит интеллектуальный расчет срезов (12% от краев), чтобы предотвратить искажение на смартфонах.
