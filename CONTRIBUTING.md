## 🚀 Быстрый старт

1. Сделайте **Fork** репозитория [`OctoCore-Dev/themes`](https://github.com/OctoCore-Dev/themes).
2. Склонируйте свой форк:
   ```bash
   git clone https://github.com/<your-username>/themes.git
   cd themes
   ```
3. Скопируйте шаблонную тему из папки `templates/starter-theme` в `themes/<id-вашей-темы>`:
   ```bash
   cp -r templates/starter-theme themes/my-awesome-theme
   ```
4. Отредактируйте `theme.json` и замените графические ассеты на свои.
5. Запустите валидатор:
   ```bash
   npm run validate
   # или напрямую:
   node scripts/build-catalog.js
   ```
6. Отправьте Pull Request в ветку `main`.

## 📁 Структура папки темы

Каждая тема располагается в отдельной директории внутри `themes/<id-темы>/`:

```text
themes/my-awesome-theme/
├── theme.json                     # Основной манифест темы (обязателен)
├── icon.png                       # Квадратная иконка темы для каталога (256x256 или 512x512)
├── preview.jpg                    # Скриншот-превью для каталога (16:9, например 1280x720)
└── assets/                        # Медиа-ресурсы темы
    ├── bg.jpg                     # Фоновое изображение (или постер для видео)
    ├── bg.mp4                     # (Опционально) Зацикленное фоновое видео (60 FPS, H.264)
    ├── buttons/                   # Кнопки подключения VPN
    │   ├── btn_idle.png           # Статичная кнопка в покое
    │   ├── btn_connecting.png     # Статичная кнопка при подключении
    │   ├── btn_active.png         # Статичная кнопка в активном режиме
    │   ├── btn_error.png          # Статичная кнопка при ошибке
    │   ├── button_idle.webp       # (Опционально) Анимированная кнопка в покое
    │   ├── button_connecting.webp # (Опционально) Анимированная кнопка при подключении
    │   ├── button_active.webp     # (Опционально) Анимированная кнопка в активном режиме
    │   └── button_error.webp      # (Опционально) Анимированная кнопка при ошибке
    ├── frames/                    # (Опционально) Экранные рамки 9-Slice
    │   └── screen_frame.png       # PNG рамка с прозрачным центром
    ├── particles/                 # (Опционально) Спрайты для системы частиц
    │   └── spark.png              # Прозрачный PNG спрайт (32x32 / 64x64)
    └── sounds/                    # (Опционально) Звуковые эффекты
        ├── click.wav              # Звук нажатия на элементы интерфейса
        ├── connect.wav            # Звук успешного подключения VPN
        └── disconnect.wav         # Звук отключения VPN
```

## 🛡️ Требования к ассетам

| Ассет | Форматы | Макс. размер | Особенности |
| :--- | :--- | :--- | :--- |
| **Иконка** (`icon.png`) | PNG | 1 МБ | Пропорции 1:1 (от 256x256 до 512x512), без альфа-артефактов |
| **Превью** (`preview.jpg`) | JPG, WebP | 2 МБ | Пропорции 16:9 (1280x720), реальный вид интерфейса темы |
| **Фон** (`bg.jpg` / `bg.mp4`) | JPG, WebP, MP4, WebM | 5 МБ (фото) / 20 МБ (видео) | Для видео: кодек H.264, профиль baseline/main, без звука, бесшовный луп |
| **Кнопки** (`buttons/*`) | PNG, WebP | 5 МБ на файл | **Обязателен альфа-канал (прозрачность)**. Форма круглая или органическая |
| **Звуки** (`sounds/*`) | WAV, MP3 | 2 МБ на файл | Стерео или моно, частота 44.1/48 кГц, длительность до 5 сек |
| **Шрифты** (`fonts/*`) | TTF, OTF | 5 МБ | Открытая лицензия (OFL, Apache 2.0) |

> ⚠️ **Общий лимит темы:** суммарный размер всех файлов одной темы в распакованном виде не должен превышать **35 МБ**.

## 🖼️ Адаптивные 9-Slice рамки

Если тема использует экранную декоративную рамку (`screenFrame`), она **обязана** корректно отображаться как на широких мониторах ПК (16:9), так и на узких экранах смартфонов (9:20).

Для этого укажите отступы срезов в пикселях:

```json
"decorations": {
  "screenFrame": "assets/frames/screen_frame.png",
  "frameSlice": {
    "top": 80,
    "right": 80,
    "bottom": 80,
    "left": 80
  },
  "frameSliceMobile": {
    "top": 70,
    "right": 60,
    "bottom": 70,
    "left": 60
  }
}
```

* Углы (`top-left`, `top-right`, `bottom-left`, `bottom-right`) фиксируются 1:1 без искажений.
* Центральные стороны масштабируются под размер экрана устройства.
* Центр рамки должен быть прозрачным, чтобы не закрывать контент приложения.
* **Подробное руководство:** см. [Nine-Patch-Frames в Вики](https://github.com/OctoCore-Dev/themes/wiki/Nine-Patch-Frames).

## 🔘 4 состояния кнопки VPN

Кнопка подключения имеет 4 интерактивных состояния:

1. **`buttonImageIdle` / `buttonVideoIdle`**: состояние ожидания (VPN выключен).
2. **`buttonImageConnecting` / `buttonVideoConnecting`**: рукопожатие и подключение.
3. **`buttonImageActive` / `buttonVideoActive`**: защищенный туннель активен.
4. **`buttonImageError` / `buttonVideoError`**: ошибка связи или блокировка узла.

### Анимированный WebP с прозрачностью
Для плавных 30–60 FPS анимаций используйте Animated WebP (`.webp`) с 8-битным альфа-каналом.

Пример сборки из секвенции PNG через FFmpeg:
```bash
ffmpeg -framerate 30 -i frame_%03d.png -vcodec libwebp -lossless 0 -q:v 80 -loop 0 button_idle.webp
```

## ✅ Локальная проверка валидатором

Перед созданием Pull Request обязательно запустите локальную проверку:

```bash
npm run validate
```

Валидатор автоматически проверит:
- Синтаксис и схему `theme.json` (соответствие `schemas/theme.v4.json`).
- Безопасность путей (защита от Path Traversal `../`).
- Магические сигнатуры байтов (отсутствие битых файлов или замаскированных скриптов).
- Лимиты размеров файлов и суммарный объем темы.
- Доступность обязательных ассетов (`icon.png`, `preview.jpg`, `bg.jpg`/`bg.mp4`).

## 📬 Создание Pull Request

1. Создайте отдельную ветку:
   ```bash
   git checkout -b theme/my-awesome-theme
   ```
2. Закоммитьте изменения:
   ```bash
   git add themes/my-awesome-theme
   git commit -m "feat(theme): add My Awesome Theme"
   ```
3. Отправьте ветку в свой форк:
   ```bash
   git push origin theme/my-awesome-theme
   ```
4. Откройте **Pull Request** в репозиторий `OctoCore-Dev/themes` (ветка `main`).
5. Заполните PR-шаблон и прикрепите скриншот превью.
6. Дождитесь успешного прохождения GitHub Action `Validate Themes & Build Catalog`.

## 🎖️ Критерии верификации (OctoCore Verified)

Статус официальной/проверенной темы присваивается темам, которые:
- Имеют уникальный авторский дизайн без нарушения чужих авторских прав.
- Содержат плавные 4-состоятельные кнопки (желательно Animated WebP).
- Имеют оптимизированный вес (быстрая загрузка на мобильных сетях).
- Протестированы на смартфонах Android/iOS и на десктопе (Windows/macOS/Linux).
